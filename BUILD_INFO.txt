NexoWatt Devices 0.5.141 – ABL eMH1 Strom-/Alias-Rückmeldung

Base: 0.5.140 release-safe (Alfen ACE write audit, TA CMI, Weidmüller, Sungrow fast feedback)

ABL eMH1 / EVCC2/3 changes:
- fixed alias semantics: the charging-current command is a per-phase IEC 61851 limit and must not be compared with L1+L2+L3
- aliases.r.currentA and compatibility alias aliases.r.currentTotalA now report the highest measured phase current
- added explicit readbacks aliases.r.currentL1, currentL2, currentL3
- added aliases.r.currentPhaseSumA only for diagnostics and estimated-power calculation
- added applied current-limit readbacks aliases.r.currentLimitA and aliases.r.currentLimitPct
- kept estimated power based on (L1+L2+L3) x 230 V
- corrected the IEC 61851 boundary: 85 % PWM = 51 A; high-current formula starts above 85 %
- retained the proven Modbus-ASCII addresses/scaling: 0x002F applied Ic PWM, 0x0030..0x0032 phase currents, 0x0014 Icmax write

Field example:
- command: 10 % PWM = 6 A per phase
- measured: 5.5 A / 5.5 A / 5.5 A
- comparable live current: 5.5 A
- phase-current sum: 16.5 A
- estimated power: 16.5 A x 230 V = 3,795 W
