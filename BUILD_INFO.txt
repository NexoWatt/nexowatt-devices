NexoWatt Devices 0.5.142 – ABL eMH1 EVCC2/3 exact Modbus-ASCII read groups

Base: 0.5.141 ABL current/alias correction

Root cause fixed:
- the generic Modbus grouping combined ABL register 0x0001/R2 and 0x0003/R1 into one unsupported 0x0001/R3 request
- transmitted invalid field frame was :010300010003F8
- EVCC2/3 intentionally remains silent for invalid read requests, therefore the adapter logged a 2000 ms timeout

Correct requests in 0.5.142:
- :010300010002F9  (UID1 FC3 start 0x0001 quantity 2)
- :010300030001F8  (UID1 FC3 start 0x0003 quantity 1)
- 0x0006..0x0007 remains one exact R2 request
- 0x002E..0x0032 remains one exact R5 request

Implementation:
- optional source.readRequestGroup boundaries added to the generic Modbus group builder
- only explicitly tagged sources are separated; all untagged templates retain existing grouping behaviour
- ABL runtime/admin templates synchronized
