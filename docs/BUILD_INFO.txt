NexoWatt Devices 0.5.154 - EV charger live-status freshness hardening

Base:
- release 0.5.153
- all 182 templates, existing raw datapoints and legacy aliases remain unchanged
- TESVOLT MQTT V2, FENECON ctrlBalancing0, Alfen, ABL and all prior fixes remain intact

Root cause:
- the generic runtime state cache correctly suppressed unchanged values
- idle chargers therefore kept old ioBroker timestamps for 0 W / false / unchanged status values
- NexoWatt UI measurement freshness could interpret those old timestamps as stale although heartbeat communication remained healthy

Implementation:
- generic handling for Alias Contract deviceClass evCharger (all EVCS/EVSE templates)
- safety-relevant legacy and aliases.v1 readbacks are periodically re-published after real successful snapshots
- default bounded refresh cadence: 5 seconds, minimum 1 second, maximum 10 seconds
- online timestamp also refreshes only on real incoming data
- static metadata, energy counters and command aliases remain change-only
- empty/disconnected/error snapshots never fabricate freshness

Packaging:
- normal source ZIP only
- no publish-safe.cmd, TGZ, RAR, nested ZIP or node_modules
